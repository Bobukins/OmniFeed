* В решении кейса Voronka со стороны back-end части используется микросервисная архитектура, для обеспечения модульности и отказоустойчивости платформы
* Задейственный стек технологий на данной стадии разработки: nginx, docker, uvicorn, FastAPI, PostgreSQL, 
* Дальнейшие технологии, требуемые для улучшения работы  back-end части: 
	* Redis(кэширование запросов пользователей и их сессий), Apache 
	* Kafka(буферизация запросов на высоконагруженных сервисах)
	* MLFlow для оценки качества работы модели и вывода подробной статистики их CI/CD 
	* Grafana + Prometeus для сбора логов системы
### Реализованные сервисы
* ClientServer - для клиент-серверного взаимодействия
* SocialContentGate - сервис, унифицирующий сбор данных с различных платформ
* MLService - сервис, с различными моделями для анализа данных, рекомендаций контента и т.п (ветка ML)
### Сервисы, которые будут реализованы в дальнейшем
* NetworkingAlgWorker - сервис, в котором реализуется алгоритм поиска похожего контента в сети интернет
